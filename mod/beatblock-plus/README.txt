Beatblock Online - BeatblockPlus 2.x distribution

Preferred installation:
1. Install Lovely and BeatblockPlus 2.x first.
2. In Beatblock, open Mods.
3. Drag the unopened Beatblock Online BeatblockPlus release ZIP into that menu.
4. Restart Beatblock when prompted.

Manual installation: extract this BeatblockOnline folder to:
%APPDATA%\Beatblock\Mods\BeatblockOnline

Confirm this file exists:
%APPDATA%\Beatblock\Mods\BeatblockOnline\mod.json

Do not install the standalone distribution at the same time. The Windows
companion must be running for online play and OBS exports.

Full instructions: docs/injection.md in the project repository.
