Beatblock Online - Standalone Lovely distribution

1. Install Lovely's version.dll beside Beatblock.exe.
2. Extract this BeatblockOnline folder to:
   %APPDATA%\Beatblock\Mods\BeatblockOnline
3. Confirm this file exists:
   %APPDATA%\Beatblock\Mods\BeatblockOnline\lovely\bootstrap.toml

Do not use this distribution when BeatblockPlus is installed. Do not install
both Beatblock Online distributions. The Windows companion must be running
for online play and OBS exports; offline practice telemetry can still load.

Full instructions: docs/injection.md in the project repository.
