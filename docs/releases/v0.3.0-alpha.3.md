# Beatblock Online v0.3.0-alpha.3

`v0.3.0-alpha.3` moves Beatblock Online to the protocol-v3 room, chart-transfer,
Commentator, and native OBS workflows. It also hardens authentication, local
access, installer upgrades, resource limits, and release provenance.

## Download

Most players need only `BeatblockOnlineInstaller.exe` from this GitHub Release.
It includes the runtime, supported Lua adapters, Lovely Injector, and OBS
source. The release also provides the OBS DLL, two mod ZIPs, and
`SHA256SUMS.txt` for inspection or manual development workflows.

## Highlights

- Introduces dedicated Room, Setlist, Broadcast, History, Settings, and Help
  workspaces with host-managed Commentator access and chart transfer.
- Makes room and scoring state host-authoritative and authenticates the SPAKE
  and QUIC join path.
- Protects local IPC and browser APIs with owner-only transport and bounded,
  authenticated messages.
- Reconstructs delayed native OBS views from final palette and accessibility
  shading, authored backgrounds, gameplay effects, HUDs, and Results.
- Adds reversible direct-launch installation, upgrade rollback, Lovely
  preservation, OBS-running detection, and deterministic installer assets.
- Pins native inputs and GitHub Actions, verifies x64 artifacts and exact ZIP
  contents, and publishes provenance attestations.

## Upgrade

1. Close Beatblock and OBS.
2. Run `BeatblockOnlineInstaller.exe`.
3. Select the existing game folder and choose **Install / Update**.
4. Restart OBS before adding **Beatblock Online Player Stream** sources.

The transaction preserves user data and unrelated mods. The installer also
provides repair, restore, and uninstall operations.

## Compatibility and known limitations

This is an alpha prerelease. Protocol-v3 peers must use compatible Online
builds. Automated and isolated-machine gates do not replace the pending
physical two-machine WAN and long-duration OBS audio/video trials.
