# Beatblock Online v0.3.0-beta.4

`v0.3.0-beta.4` improves Beatblock compatibility, chart transfer, dashboard
readability, and per-renderer OBS audio. It resolves
[#15](https://github.com/DupeisTaken/beatblock-online/issues/15) through
[#19](https://github.com/DupeisTaken/beatblock-online/issues/19).

## Download

Most players need only `BeatblockOnlineInstaller.exe` from this GitHub Release.
It embeds the runtime, supported Lua adapters, Lovely Injector, and native OBS
source. The OBS DLL, mod ZIPs, and `SHA256SUMS.txt` support inspection and
manual development workflows.

## Highlights

- Accepts structurally valid newer Beatblock builds while clearly separating
  the tested baseline from accepted-but-unverified upstream versions.
- Uses the exact displayed Beatblock version and bracketed build token for
  strict same-build rooms, with an explicit **Allow Any** casual option.
- Adds consent-aware manual or one-time automatic requests for a missing locked
  custom chart.
- Shows Online, protocol, tested Beatblock, and detected Beatblock identities
  separately in Settings.
- Reorganizes setlist controls and bounds long chart, variant, status, and error
  text within the 600×360 dashboard.
- Gives each OBS Player Stream a private renderer-targeted audio capture with
  independent synchronization.

## Upgrade

1. Close Beatblock and OBS.
2. Run this release's installer and choose **Install / Update**.
3. Optionally install the OBS Studio 32 source, then restart both applications.
4. Confirm the intended Beatblock build across participants; use **Allow Any**
   only for an intentional compatibility test.
5. Verify each A–D source assignment and audio route on the production machine.

## Compatibility and known limitations

The installer accepts newer Beatblock builds, but only
`1.7.1a (Early Access)[d40b7083]` was verified for this release. Later builds
remain unverified until their exact displayed version and bracketed build token
pass the documented compatibility suite. Windows process-loopback capture does
not itself silence renderer audio, so broadcasters must follow the routing
guidance. This remains a beta prerelease.
