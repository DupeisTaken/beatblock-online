# Beatblock Online v0.3.0

`v0.3.0` is the first official Beatblock Online release. It promotes the
protocol-v3 direct-IP room, installer, dashboard, broadcast, chart-transfer,
and results workflows developed through the alpha and beta series, with final
launch-path and room-policy hardening from
[#43](https://github.com/DupeisTaken/beatblock-online/pull/43) and
[#44](https://github.com/DupeisTaken/beatblock-online/pull/44).

## Download

Most players should download only `BeatblockOnlineInstaller.exe` from this
GitHub Release. It contains the runtime, supported Lua adapters, Lovely
Injector, and optional native OBS source. `SHA256SUMS.txt`, the standalone OBS
DLL, and both mod ZIPs are provided for verification and advanced/manual use.

## Highlights

- **Host-owned race rules:** the host can set game speed, VFX, Taps, Sides,
  Barelies, and Restart On before a race. Players can inspect those values but
  cannot override them; their own saved preferences return after the attempt.
- **No silent policy downgrade:** current rooms reject older protocol-v3
  runtimes that cannot enforce host modifiers. If a connection says a peer
  must update, install this release on every room machine.
- **Reliable international chart launches:** custom chart and variant paths
  containing non-ASCII characters now survive the Windows renderer launch
  boundary instead of being damaged by environment encoding.
- **Complete competition flow:** password-protected Player and Spectator
  roles, host approval, exact chart checks, synchronized starts, run validity,
  ordered sets, results, reconnect handling, and optional custom-chart transfer
  are available from the in-game Online dashboard.
- **Installer and broadcast tooling:** the self-contained installer supports
  install/update, repair, uninstall, status refresh, and verified self-update.
  OBS sources support four player video streams plus independent player and
  autoplay audio routes.
- **Player-oriented diagnostics:** the Player Guide explains installer,
  connection, chart, readiness, result, modifier, and OBS failures using the
  labels shown in the released interface.

## Upgrade

1. Close Beatblock. Close OBS too if you install or update its optional source.
2. Run `BeatblockOnlineInstaller.exe` and choose **Install / Update**.
3. Restart Beatblock and OBS after installation.
4. Open **Online** and confirm the header shows `v0.3.0 / READY`.
5. Confirm every host, player, spectator, commentator, and renderer machine
   uses `v0.3.0` before creating the room.

Existing Player Stream scene items remain video-only. Add and route the desired
Beatblock Online Audio A-D or Autoplay source separately when broadcast audio
is needed.

## Compatibility and known limitations

The verified Beatblock baseline is
`1.7.1a (Early Access)[d40b7083]` on Windows 10 2004+ and Windows 11 x64.
Newer structurally valid Beatblock builds may install, but remain unverified
until their displayed version and bracketed build token pass the compatibility
suite. Same-build rooms remain the default.

The installer is not Authenticode-signed, so Windows may show **Unknown
publisher**. Verify the published checksum and GitHub attestation. Physical
OBS 32.1.2 color/audio routing, process-loopback behavior after desktop mute,
and long-duration drift remain environment-specific checks tracked in
[#28](https://github.com/DupeisTaken/beatblock-online/issues/28). Test the full
scene and network path before a live event.
