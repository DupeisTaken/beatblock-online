# Beatblock Online v0.3.0-beta.2

`v0.3.0-beta.2` is a correctness and broadcast-consistency update. It repairs
false run invalidations, makes retries and reconnects attempt-aware, keeps OBS
score and Results output tied to the delayed source player, and supports custom
OBS installation locations.

## Download

Most players need only `BeatblockOnlineInstaller.exe` from this GitHub Release.
It embeds the runtime, Lua adapters, Lovely Injector, and OBS source. The
separate OBS DLL, mod ZIPs, and `SHA256SUMS.txt` are for inspection or manual
development workflows.

## Highlights

- Rejects duplicate names clearly and allows a clean retry without a reconnect
  loop.
- Adds host-controlled **Run Checks**, attempt IDs, idempotent starts, and
  correct competitive INVALID versus DNF handling.
- Publishes a final normalized score at the Results boundary so the last note
  cannot be lost.
- Preserves verdicts through reconnects and exposes complete reasons through
  **Run Details**.
- Keeps delayed OBS accuracy, totals, timing, and Results sourced from the same
  player sample as the rendered frame.
- Accepts validated custom or portable OBS roots and remembers a successful
  selection across installer runs.

## Upgrade

1. Close Beatblock and OBS.
2. Run this release's installer and choose **Install / Update**.
3. Select the OBS folder before enabling the optional source when OBS is
   portable or outside Program Files.
4. Restart Beatblock and OBS, and use the same Online release across the room.

## Compatibility and known limitations

This is a beta prerelease. It preserves unrelated mods, OBS scenes, settings,
and match history. Physical multi-network WAN and long-duration four-renderer
trials remain environment-specific release gates.
