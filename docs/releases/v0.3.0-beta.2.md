# Beatblock Online v0.3.0-beta.2

`v0.3.0-beta.2` is a correctness and broadcast-consistency update for the
direct-IP beta. It repairs false run invalidations, makes retries and reconnects
attempt-aware, keeps OBS score/Results output tied to the delayed source player,
and makes custom OBS installations selectable in the Windows installer.

## What players should download

Most players need only `BeatblockOnlineInstaller.exe` from the GitHub Release.
It embeds the runtime, both supported Lua distributions, Lovely Injector, and
the native OBS source. The separate DLL and ZIP assets are for inspection or
manual development workflows:

- `beatblock-online-obs.dll`;
- `beatblock-online-standalone-0.3.0-beta.2.zip`;
- `beatblock-online-beatblock-plus-0.3.0-beta.2.zip`;
- `SHA256SUMS.txt`.

## Player-visible fixes

- Rejects duplicate display names with **username taken** instead of silently
  creating `Name (2)`. The rejected client returns to Offline and can retry with
  another name without entering a reconnect loop.
- Preserves INVALID and DNF verdicts through authenticated reconnects. Results
  paginate every participant and expose the complete reason through
  **Run Details**.
- Adds a host-controlled **Run Checks** policy. Competitive rooms invalidate
  retries and unrecoverable event gaps. Casual rooms replace a retried attempt
  and recover from cumulative score updates, while impossible counters and DNF
  completion rules remain enforced.
- Clears Beatblock's retained native Player/entity state when leaving Online so
  it cannot continue updating beside the destination state's Player.

## Run correctness

- Gives every native attempt its own bounded `runId`, ignores late events from
  replaced attempts, and accepts duplicate start delivery idempotently.
- Matches Beatblock's real Mine/MineHold counter update order, preventing an
  intermediate native counter state from being mislabeled impossible.
- Advances score sequence numbers only after a cumulative update enters the
  bounded IPC queue. Rejected telemetry records an integrity reason without
  disconnecting the game/runtime pipe.
- Distinguishes competitive INVALID from DNF. Explicit quit, incomplete finish,
  launch timeout, and disconnect expiry remain DNF even when Run Checks are off.

## OBS and installer

- Aligns source-authored accuracy, totals, average timing offset, and the final
  Results marker with the same delayed player sample used by each OBS video
  frame. A hidden renderer cannot replace these values with replay-derived data.
- Uses Beatblock's built-in default Cranky costume in disposable renderer
  profiles instead of inheriting the host save's selected costume.
- Clears stable Stream A-D text files when a slot is unassigned or its
  participant disappears, preventing stale names/scores from remaining in OBS.
- Adds an editable OBS location and **Browse...** control. The installer accepts
  the OBS root, `bin`, `bin\64bit`, or `obs64.exe`, rejects invalid explicit
  selections without fallback, carries the root through UAC, and remembers a
  successful custom/portable installation.

## Upgrade notes

1. Close Beatblock and OBS.
2. Run `BeatblockOnlineInstaller.exe` from this release and choose
   **Install / Update**.
3. If OBS is portable or installed outside Program Files, select its folder in
   the OBS field before enabling the optional source.
4. Restart Beatblock and OBS. Host and Player must use the same release.

The installer preserves unrelated mods, OBS scenes/plugins, settings, and match
history. This remains a beta prerelease: the repository's physical multi-network
WAN and long-duration four-renderer trials are still required for environment-
specific certification.
