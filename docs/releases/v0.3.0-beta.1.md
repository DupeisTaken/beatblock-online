# Beatblock Online v0.3.0-beta.1

`v0.3.0-beta.1` is the first beta of the direct-IP competition system. It
combines the hardened protocol-v3 runtime and installer with completed host,
setlist, Commentator, and native OBS workflows.

## Download

Most players need only `BeatblockOnlineInstaller.exe` from this GitHub Release.
It embeds the runtime, supported Lua adapters, Lovely Injector, and native OBS
source. The OBS DLL, mod ZIPs, and `SHA256SUMS.txt` remain available for
inspection and manual development workflows.

## Highlights

- Adds an explicit **Play** or **Direct** host choice so a directing host can
  manage a room without consuming a racer slot.
- Prevents Escape and controller pause actions from stopping active online
  gameplay.
- Completes ordered setlists, next-chart continuation, participant inspection,
  host approval, exact chart verification, and role-aware actions.
- Drives four independently configurable OBS renderer slots through native
  gameplay timing with delayed Full or Clean views.
- Preserves host authority, authenticated networking, owner-only IPC, chart
  consent, transactional installation, and bounded runtime resources.
- Enforces pinned dependencies, exact release tags, deterministic payloads,
  and artifact verification before publication.

## Upgrade

1. Close Beatblock and OBS.
2. Run `BeatblockOnlineInstaller.exe`.
3. Confirm the selected game folder and choose **Install / Update**.
4. Restart OBS before testing Player Stream sources.

User data, unrelated mods, and installer rollback controls are preserved.

## Compatibility and known limitations

All room participants should use the same beta. Physical multi-network WAN and
long-duration OBS trials remain prerequisites for a stable release. Validate
the production network, graphics, and audio environment before an event.
