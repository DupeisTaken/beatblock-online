# Beatblock Online v0.3.0-beta.1

`v0.3.0-beta.1` is the first beta of the direct-IP competition system. It
combines the hardened protocol-v3 runtime and installer with the completed host,
setlist, Commentator, and native OBS workflows. The beta designation means the
core product path is feature-complete enough for broader testing; the physical
WAN and long-duration OBS trials documented in the repository still remain
release gates for a stable build.

## Download

Most players need only `BeatblockOnlineInstaller.exe` from the GitHub Release.
It embeds the runtime, both supported Lua distributions, the reviewed Lovely
Injector build, and the native OBS source.

The release also contains:

- `beatblock-online-obs.dll` for manual OBS source inspection;
- `beatblock-online-standalone-0.3.0-beta.1.zip`;
- `beatblock-online-beatblock-plus-0.3.0-beta.1.zip`;
- `SHA256SUMS.txt`.

## Beta highlights

### Hosting and race control

- Adds an explicit **Play** or **Direct** choice when creating a room. A
  directing host controls the room without consuming a racer slot or appearing
  in the rankings, and can switch back before a later race.
- Prevents Escape and controller pause actions from stopping an active online
  chart while retaining Beatblock's normal pause behavior offline.
- Completes ordered setlist management, next-chart continuation, participant
  inspection, host approval, exact chart verification, and role-aware next
  actions in the in-game workspace.

### Native OBS output

- Drives isolated renderer processes through Beatblock's native gameplay timing
  instead of reconstructing animation state outside the game.
- Preserves final-shaded Full output and palette-correct Clean output, including
  authored backgrounds, video, entities, effects, HUDs, and Results.
- Aligns delayed telemetry, tap judgements, paddle state, pre-roll, and the first
  scoring-note barrier across all assigned streams.
- Keeps four independently configurable Stream A-D slots with bounded delay,
  720p/1080p and 30/60 fps controls, Commentator mirrors, health reporting, and
  deterministic visual tests.

### Shippable runtime and installer

- Enforces host authority, authenticated SPAKE/QUIC sessions, owner-only local
  IPC, loopback API credentials, bounded queues and files, transactional
  configuration, and explicit runtime shutdown.
- Hardens chart-transfer consent, installer rollback, direct-launch ownership,
  Lovely preservation, OBS plugin replacement, and elevated-helper path checks.
- Uses the single self-contained `BeatblockOnlineInstaller.exe` name locally and
  on GitHub, with all generated files kept outside version control.

### Release verification

- Pins third-party GitHub Actions and native dependencies, audits the supported
  Windows Rust graph, validates generated protocol and mod payloads, and binds
  the OBS DLL to its reviewed source through a SHA-256 manifest.
- Runs protocol, Rust, Lua, UI, renderer, stress, installer, archive, PE, and
  checksum gates before a tagged release can be published.
- Publishes prerelease artifacts only when the pushed tag exactly matches the
  package version.

## Upgrade

1. Close Beatblock and OBS.
2. Download and run `BeatblockOnlineInstaller.exe`.
3. Confirm the selected Beatblock folder, then choose **Install / Update**.
4. Restart OBS before testing **Beatblock Online Player Stream** sources.

The installer preserves user data and unrelated mods. Use **Restore Game Files**
or **Uninstall** from the same installer if rollback is required.
