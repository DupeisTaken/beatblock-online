# Beatblock Online v0.3.0-beta.3

`v0.3.0-beta.3` is a gameplay-correctness, update-discovery, and OBS broadcast
reliability release. It resolves GitHub issues
[#9](https://github.com/DupeisTaken/beatblock-online/issues/9),
[#10](https://github.com/DupeisTaken/beatblock-online/issues/10),
[#11](https://github.com/DupeisTaken/beatblock-online/issues/11),
[#12](https://github.com/DupeisTaken/beatblock-online/issues/12),
[#13](https://github.com/DupeisTaken/beatblock-online/issues/13), and
[#14](https://github.com/DupeisTaken/beatblock-online/issues/14).

## What players should download

Most players need only `BeatblockOnlineInstaller.exe` from this GitHub Release.
It embeds the runtime, both supported Lua adapters, the pinned no-console Lovely
Injector, and the native OBS 32 source. The remaining assets support inspection
and manual installation:

- `beatblock-online-obs.dll`;
- `beatblock-online-standalone-0.3.0-beta.3.zip`;
- `beatblock-online-beatblock-plus-0.3.0-beta.3.zip`;
- `SHA256SUMS.txt`.

## Fixed issues

### Version and update discovery — #9

Settings now displays the compiled Beatblock Online version and its
Stable/Preview channel. **Check for updates** queries GitHub Releases
asynchronously with a timeout, compares semantic versions rather than strings,
ignores drafts, and excludes prereleases for stable builds. When a compatible
newer release exists, Settings can open its release page.

### Ladybug chart crash — #10

Beatblock's Ladybug manager calls `GameManager.getTapInputs()` without a Lua
receiver. The previous wrapper forwarded the call and then dereferenced the
missing `self`, crashing when Ladybug jumped after a tap. The wrapper now keeps
the native invocation and uses a nil-safe active GameManager only when optional
beat-offset conversion is available.

### False final-note DNF/INVALID results — #11

Beatblock can enter Results during the same frame as the final scoring
opportunity. That transition skips the remainder of the normal tap update, so
Online could finalize the previous live snapshot—for example, 1156 of 1157
opportunities—even though native Results accepted the completed chart. The
Results boundary now always publishes a normalized terminal score snapshot
before `run.finished`. Genuine quits, retries, incomplete attempts, and
disconnect expiry retain their existing DNF/INVALID behavior.

### Special-character custom charts — #12

Custom selection now uses Beatblock's authoritative UTF-8 package filename
instead of deriving a path from rendered or localized title text. Raw
`songName` metadata is preserved, and both current `manifest.json` packages and
legacy `level.json` packages are supported. Titles and paths containing
punctuation, division signs, or other Unicode characters can be selected and
verified normally.

### Renderer relaunch crash, visibility, and audio bleed — #13

A renderer relaunched after the first match could receive the previous Results
keyframe before threaded Game initialization created its VFX state. That stale
transition could crash the child. Relaunched slots now remain gated until the
next authoritative `begin_run`, clear their previous mappings and buffers, and
ignore Results until initialization is complete. Renderer windows are hidden
through their SDL-owned window handles with Windows fallbacks, and every hidden
child remains muted.

### Integrated OBS Player Stream audio — #14

The Player Stream source previously advertised video only. It now creates OBS's
Application Audio Capture child, reroutes the visible Beatblock process into the
Player Stream, advertises audio support, and applies a configurable sync delay
that defaults to the 500 ms video buffer. Source properties expose an audio
toggle, OBS window selector, sync delay, and help text. Missing Application
Audio Capture support degrades safely to video-only, and teardown removes the
route without leaving a capture child behind.

OBS Studio 32 is required for the packaged source. Hidden renderer processes
remain muted; enable audio on only one Player Stream when a scene contains
multiple reconstructed streams.

## Upgrade notes

1. Close Beatblock and OBS.
2. Download and run this release's `BeatblockOnlineInstaller.exe`.
3. Choose **Install / Update**. Enable the optional OBS source only for OBS
   Studio 32, and select the OBS root if it is portable or installed outside
   Program Files.
4. Restart Beatblock and OBS.
5. In OBS, review each Player Stream's audio target and set **Audio sync delay**
   to the same value used by that stream's Advanced Export configuration.
6. Confirm every host, Player, Spectator, and Commentator uses
   `v0.3.0-beta.3` before starting a room.

The installer preserves unrelated mods, OBS scenes/plugins, settings, and match
history. This remains a beta prerelease; environment-specific OBS audio routing,
multi-network WAN behavior, and long-duration four-renderer operation should be
confirmed on the production broadcast machine before an event.
