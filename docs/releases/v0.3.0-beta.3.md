# Beatblock Online v0.3.0-beta.3

`v0.3.0-beta.3` focuses on gameplay correctness, update discovery, and OBS
broadcast reliability. It resolves
[#9](https://github.com/DupeisTaken/beatblock-online/issues/9) through
[#14](https://github.com/DupeisTaken/beatblock-online/issues/14).

## Download

Most players need only `BeatblockOnlineInstaller.exe` from this GitHub Release.
It embeds the runtime, supported Lua adapters, Lovely Injector, and OBS source.
The other assets support inspection and manual installation.

## Highlights

- Adds asynchronous semantic-version update checks with Stable and Preview
  channels and a link to the selected GitHub Release.
- Fixes the Ladybug chart crash caused by a receiver-less native tap-input call.
- Publishes terminal score state before Results to prevent a valid final note
  becoming DNF or INVALID.
- Uses authoritative UTF-8 package filenames for custom charts, including
  punctuation and Unicode.
- Prevents stale Results state from crashing relaunched renderers and keeps
  hidden child processes muted.
- Adds integrated Player Stream audio capture with an adjustable sync delay and
  a safe video-only fallback.

## Upgrade

1. Close Beatblock and OBS.
2. Run this release's installer and choose **Install / Update**.
3. Enable the OBS source only for OBS Studio 32 and select a custom root when
   necessary.
4. Restart both applications and verify the Player Stream audio target and sync
   delay.
5. Confirm every room participant uses `v0.3.0-beta.3`.

## Compatibility and known limitations

This is a beta prerelease. Application Audio Capture support and routing depend
on the production OBS and Windows audio environment. Multi-network WAN behavior
and long-duration renderer operation also require physical verification.
