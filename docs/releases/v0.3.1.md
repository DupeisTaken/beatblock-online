# Beatblock Online v0.3.1

`v0.3.1` makes local chart validation explicit when joining a room. Players can
now open Beatblock Freeplay or the custom-chart browser directly from their
roster entry instead of being limited to the source inferred from room
metadata.

## Download

Most players should download `BeatblockOnlineInstaller.exe` from this GitHub
Release. It contains the runtime, supported Lua adapters, Lovely Injector, and
optional native OBS source. Checksums, the standalone OBS DLL, and both mod
ZIPs are also included for verification and advanced/manual use.

## Highlights

- **Freeplay during validation:** an unverified Player now has dedicated
  **Freeplay** and **Custom** buttons for selecting the matching local chart.
- **Safe matching:** choosing either browser does not weaken room rules. The
  runtime still compares the chart identity, variant, and expected note count
  with the host's authoritative lock.
- **Compact native layout:** both choices share one action row, leaving chart
  transfer and room controls visible at 600x360.

## Upgrade

1. Close Beatblock. Close OBS too when updating its optional source.
2. Download and run `BeatblockOnlineInstaller.exe`.
3. Choose **Install / Update**, then restart Beatblock and OBS.
4. Open **Online** and confirm the header shows `v0.3.1 / READY`.
5. Install the same release on every room machine before creating a session.

## Compatibility and known limitations

The verified Beatblock baseline remains
`1.7.1a (Early Access)[d40b7083]` on Windows 10 2004+ and Windows 11 x64.
Newer structurally valid Beatblock builds may install but remain unverified.

The installer is not Authenticode-signed, so Windows may show **Unknown
publisher**. Verify the published checksum and GitHub artifact attestation.
Physical OBS behavior remains dependent on the event machine; test the complete
scene and network path before a live event.
