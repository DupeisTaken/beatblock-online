# Beatblock Online v0.3.0-beta.5

`v0.3.0-beta.5` completes the installer, broadcast-audio, and dashboard
workflow work tracked in
[#20](https://github.com/DupeisTaken/beatblock-online/issues/20) through
[#26](https://github.com/DupeisTaken/beatblock-online/issues/26), plus
[#29](https://github.com/DupeisTaken/beatblock-online/issues/29).

## Download

Most players need only `BeatblockOnlineInstaller.exe` from this GitHub Release.
It embeds the runtime, supported Lua adapters, Lovely Injector, and native OBS
source. `SHA256SUMS.txt`, the standalone OBS DLL, and both mod ZIPs are also
published for verification and advanced/manual workflows.

## Highlights

- **Verified installer self-update:** **Update Installer** downloads the exact
  release executable and checksum list, requires GitHub's SHA-256 digest and
  `SHA256SUMS.txt` to agree, verifies an x64 installer with the selected
  version, promotes only an app-managed maintenance copy, and rolls back if the
  new installer does not become ready.
- **Live process refresh:** **Refresh game & OBS status** rechecks the selected
  game, Beatblock process, OBS component, and OBS process without restarting
  the installer. Game or OBS mutations fail closed while the relevant process
  is active or cannot be inspected.
- **Independent broadcast audio:** Player Stream is video-only. Separate
  Beatblock Online Audio A-D sources follow the renderer clocks, while exact
  child-PID desktop isolation avoids muting the host game or unrelated
  processes.
- **Optional autoplay mix:** Broadcast can launch an audio-only song-plus-
  perfect-hits renderer with a disposable profile and no video frame ring.
- **Clearer dashboard:** the header and Settings labels are explicit,
  one-off chart selection has its own OFFICIAL/CUSTOM picker and replacement
  confirmation, and Setlist is a six-row ordered queue with
  NOW/NEXT/QUEUED/DONE states and protected active/completed boundaries.
- **Release and issue documentation:** concise release notes now pair with
  detailed technical changelogs and a release index. Compatibility reports
  collect the exact displayed Beatblock version and bracketed build token.

## Upgrade

1. Close Beatblock and OBS.
2. Run the `v0.3.0-beta.5` installer and choose **Install / Update**.
3. Restart OBS after installing the optional source. Existing Player Stream
   scene items become video-only; add the desired A-D or Autoplay audio sources
   once and verify their routes.
4. Use **Refresh game & OBS status** after closing either application instead
   of restarting the installer.
5. Review a saved ordered set before an event: one-off **SELECT CHART** now
   replaces that set only after confirmation.

## Compatibility and known limitations

The verified Beatblock baseline remains
`1.7.1a (Early Access)[d40b7083]`. Newer structurally valid builds may be
accepted but remain unverified until their exact displayed version and
bracketed build token pass the compatibility suite.

Automated tests cover updater confinement, integrity, rollback, process
interlocks, renderer lifecycle, queue state, packaging, and deterministic
600×360 UI output. Physical OBS 32.1.2 color/audio routing, process-loopback
behavior after desktop mute, and long-run drift remain tracked in
[#28](https://github.com/DupeisTaken/beatblock-online/issues/28). Windows may
show **Unknown publisher** because hashes and GitHub attestations establish
integrity/provenance, not Authenticode identity. This remains a beta
prerelease.
