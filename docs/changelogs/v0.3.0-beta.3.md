# v0.3.0-beta.3 technical changelog

The [public release note](../releases/v0.3.0-beta.3.md) summarizes fixes for
issues [#9](https://github.com/DupeisTaken/beatblock-online/issues/9) through
[#14](https://github.com/DupeisTaken/beatblock-online/issues/14).

## Context and root causes

- **#9:** The installer exposed only its compiled version and had no
  channel-aware GitHub Release discovery.
- **#10:** Beatblock's Ladybug manager invoked `GameManager.getTapInputs()`
  without a Lua receiver, while the wrapper assumed `self` existed.
- **#11:** Beatblock could enter Results in the same frame as the final scoring
  opportunity, skipping the rest of the normal tap update.
- **#12:** Custom-chart paths were derived from rendered/localized title text
  instead of the authoritative UTF-8 package filename.
- **#13:** A relaunched renderer could consume the previous Results keyframe
  before threaded Game initialization had created its VFX state.
- **#14:** Player Stream advertised only video even though OBS's Application
  Audio Capture could provide the visible Beatblock audio route.

## Implementation details

### Version and update discovery — #9

Settings displays the compiled Online version and Stable/Preview channel.
Update checks query GitHub Releases asynchronously with a timeout, compare
semantic versions, ignore drafts, exclude prereleases for stable builds, and
offer the selected release page.

### Gameplay correctness — #10, #11, and #12

- The Ladybug wrapper preserves the native invocation and uses a nil-safe
  active GameManager only when optional offset conversion is available.
- The Results boundary always publishes a normalized terminal score before
  `run.finished`. Genuine quits, retries, incomplete runs, and disconnect expiry
  keep their DNF/INVALID behavior.
- Custom selection uses Beatblock's authoritative UTF-8 package filename,
  preserves raw `songName`, and supports both `manifest.json` and legacy
  `level.json` packages.

### Renderer lifecycle and audio — #13 and #14

- Relaunched slots remain gated until the next authoritative `begin_run`, clear
  prior mappings and buffers, and ignore Results until initialization finishes.
- Renderer windows are hidden through SDL-owned handles with Windows fallbacks;
  hidden children remain muted.
- Player Stream creates a private Application Audio Capture child, reroutes the
  visible Beatblock process, advertises audio support, and applies an adjustable
  sync delay that defaults to the video buffer.
- Missing Application Audio Capture support degrades to video-only, and
  teardown removes the private child and route.

## Migration and compatibility

Installers from this release target OBS Studio 32 for the packaged source.
Close both applications, update, restart, and review each Player Stream audio
target and delay. Use only one enabled Player Stream audio feed in a scene to
avoid duplicating the game audio. All room roles should use the same Online
release.

## Validation evidence

Release-contract tests cover semantic version/channel selection and source
version alignment. Lua regression coverage exercises the receiver-less Ladybug
call, same-frame terminal score, and Unicode package paths. Renderer lifecycle
tests cover stale keyframe gating, relaunch initialization, window hiding,
muting, and cleanup. OBS source and localization checks cover private audio
child creation, fallback, sync controls, and teardown.

## Known limitations

Application Audio Capture availability and routing remain dependent on OBS and
the Windows audio environment. Multi-network WAN behavior and long-duration
four-renderer performance still require physical production-machine trials.
