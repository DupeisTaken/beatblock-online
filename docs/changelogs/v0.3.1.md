# v0.3.1 technical changelog

The [public release note](../releases/v0.3.1.md) summarizes the player-facing
change. This changelog records its cause, implementation, and validation.

## Context and root causes

Chart validation selected a browser solely from the host lock's `official`
flag. The Player inspector therefore exposed one generic local-chart action and
could not explicitly enter Beatblock Freeplay when a player needed to locate a
built-in level. The source restriction was unnecessary because verification is
already authoritative and safely rejects the wrong candidate.

## Implementation details

- Unverified Players now receive separate **Freeplay** and **Custom** actions.
  Freeplay opens the built-in SongSelect path in `verify` mode; Custom opens the
  installed-package path in the same mode.
- The actions share one compact row. This preserves the transfer request and
  leave-room controls without overlapping the bottom workspace navigation.
- The expected source uses the cyan room accent while the alternate source
  remains available. Both paths still submit the complete chart identity,
  variant, and expected hit count to the companion.
- Shared Lua is regenerated byte-for-byte into the standalone and
  BeatblockPlus distributions.

## Migration and compatibility

The wire protocol remains version 3 and room snapshots are unchanged. Hosts
and players should run `v0.3.1` together so every machine presents the same
validation controls. The verified Beatblock baseline remains
`1.7.1a (Early Access)[d40b7083]`.

## Validation evidence

- The UI harness activates both new controls and verifies that they open the
  official and custom selectors in `verify` mode.
- All 46 deterministic dashboard scenarios pass the layout audit and reproduce
  their reviewed baselines with zero changed pixels.
- The mismatch and transfer-progress screenshots cover the new row with the
  transfer and leave-room actions still inside the participant panel.
- Source packaging validates 17 Lovely patch signatures, 29 in-game contracts,
  and both generated mod archives.
- Release metadata, documentation, formatting, protocol, Rust, and hosted
  release gates are run before the stable tag is published.

## Known limitations

- Selecting a chart does not make a mismatch valid: the exact chart, variant,
  and expected hit count must still match the host lock.
- Official Freeplay charts remain local-only and cannot be transferred from the
  host.
- The installer remains unsigned, and physical OBS/network behavior still
  requires validation on each production event machine.
