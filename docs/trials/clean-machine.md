# Clean-machine Windows trial

Test Windows 10 2004+ and Windows 11, standalone Lovely and BeatblockPlus, default and secondary Steam libraries, protected install folders, existing Lovely, unknown build, and duplicate adapter cases.

Starting with no BBT files: run `BeatblockTogetherInstaller.exe`, Install, close it, confirm no process remains, launch Beatblock from Steam, confirm the runtime does not exist before Online, open Online, complete a LAN race, Exit Online, and confirm the runtime ends. Exercise the Connect state, eight-row roster scrolling, participant card, Help drawer, all four utility overlays, confirmation dialogs, mouse focus, keyboard focus, and controller focus. Verify that closing an overlay restores the same dashboard selection and that the highlighted action follows chart verification, readiness, gameplay lockout, and Results.

Then test Repair, update, and Uninstall. Confirm no console/PowerShell/tray window appears, Steam auto-load works, only BBT-owned files are removed, optional history preservation works, a previous injector is restored, registration/firewall/plugin state is correct, and intro music does not restart when leaving Online.
